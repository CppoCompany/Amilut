# Project agents

Subagent definitions for this project live here, one Markdown file per agent.

Each file uses YAML frontmatter followed by the agent's system prompt:

```markdown
---
name: my-agent
description: When this agent should be used (triggers the Agent tool to pick it).
tools: Read, Grep, Glob   # optional; omit to inherit all tools
---

System prompt / instructions for the agent.
```
